# CTP Lab Programs

This repository contains the programs and practical exercises completed as part of the CTP laboratory coursework.

## Lab Programs

| Lab | Program |
|-----|---------|
| Lab 1 | Merge Sort |
| Lab 2 | 0/1 Knapsack |
| Lab 3 | Stack and Queue |
| Lab 4 | List and Generator Comparison |
| Lab 5 | Banking Management System |
| Lab 6 | Student Employee Data Model |
| Lab 7 | Producer Consumer |
| Lab 8 | Asynchronous Web Crawler |

## Technologies Used

- Python
- Jupyter Notebook
- Data Structures and Algorithms
- Asynchronous Programming

## Repository Structure

Each laboratory program is implemented in a separate Jupyter Notebook (`.ipynb`).

## Purpose

The repository is maintained for academic laboratory exercises and practical implementation of programming concepts.
